# Anonymous Review Package

This is a compact, reviewer-oriented evidence package for the anonymous manuscript
`When Names Mislead: Semantic-Ownership Susceptibility in LLM-Based Root Cause Analysis`.
It is designed to make the study design, estimands, integrity checks, and reported
results inspectable without distributing the full experimental workspace.

## Suggested reading order

1. `paper/main.pdf` — anonymous manuscript and appendix.
2. `protocol/confirmatory_analysis_plan_v2_3.md` — frozen SQ1/SQ2 estimands,
   invalid-output handling, bootstrap unit, and decision rules.
3. `protocol/r0_intervention_integrity_report.md` — pre-call evidence that the
   repaired intervention preserves the candidate surface and uses typed provenance.
4. `results/confirmatory_analysis_report.md` — frozen aggregate confirmatory results.
5. `results/confirmatory_interpretive_supplement.md` — post-hoc descriptive holder
   references, transition starting states, strict-switch opportunities, and input scale.
6. `results/v1_v2_integrity_audit_report.md` and
   `results/v1_v2_interpretation_boundary.md` — scope and limits of the historical
   measurement-sensitivity analysis.

## What the package supports

- Inspection of the ten-condition design over 87 confirmatory incidents and three
  preregistered permutation seeds.
- Inspection of the public-only full-surface permutation algorithm and the separate
  restricted typed-holder evaluator.
- Recalculation of headline SQ1 and SQ2 counts from frozen row-level analysis tables.
- Inspection of the validity, transition, opportunity, input-scale, and historical
  integrity summaries reported in the paper.
- Verification that the review files have not changed using `SHA256SUMS.txt`.

Run the lightweight, offline consistency check from the package root:

```bash
python code/verify_aggregates.py
```

The script uses only the Python standard library. It recomputes headline counts and
point estimates; the frozen 10,000-resample confidence intervals are supplied in the
aggregate result tables rather than regenerated by this compact package.

## Directory guide

- `paper/`: anonymous manuscript PDF.
- `protocol/`: frozen protocol, analysis plan, condition manifest, and intervention
  integrity summaries.
- `results/`: aggregate confirmatory, descriptive, validity, and historical-audit
  outputs used by the manuscript.
- `review_only/`: root, typed-holder, prediction, and case-seed tables needed for
  offline endpoint inspection. These files are separated because they contain
  evaluation-time labels and must never be provided to a model, prompt compiler, or
  intervention generator.
- `code/`: public permutation and restricted evaluation definitions plus the compact
  aggregate verifier.

## Interpretation note

The frozen cross-model confirmation rule required both evaluated model configurations
to meet the full criterion. That cross-model rule was not met. The manuscript therefore
reports the model-specific result: Qwen met the typed-holder criterion in both topology
contexts, whereas DeepSeek showed smaller positive contrasts and no strict stable switch.

The natural-name holder reference and transition decomposition are explicitly post-hoc
descriptive analyses. They supplement, rather than replace, the registered opaque-reference
SQ2 estimator.

## Deliberate exclusions

To keep the review package small, anonymous, and license-conscious, it excludes:

- raw RCA100 telemetry and answer-key files;
- full prompt payloads, raw model responses, and provider request identifiers;
- API credentials, endpoints, Authorization headers, and local configuration files;
- execution logs, caches, development canaries, and transport-repair history;
- Git history, branch names, local filesystem paths, and researcher-identifying metadata;
- complete natural-label and ownership-map directories that are unnecessary for
  understanding or checking the reported endpoints.

See `LICENSE_AND_DATA_NOTICE.md` for dataset attribution and redistribution boundaries.
